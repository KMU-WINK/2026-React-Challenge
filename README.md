# 2026-React-Challenge

# WINK 리액트 4주 챌린지 로드맵

> **왜 스터디가 아니라 챌린지인가**  
> 스터디는 "각자 읽고 와서 발표"하는 방식이라 지루하고 이탈이 잦습니다. 이 챌린지는 매주 **배운 걸 그 주 안에 직접 만들어서 제출**하는 방식으로 진행합니다. 그리고 1주차에 "내가 나중에 만들어보고 싶은 것"을 미리 정해두고, 4주차에 그걸 실제로 완성합니다. 즉 1~3주차는 4주차 파이널 프로젝트를 위한 준비 과정이자 재료입니다.

---

## 0. 챌린지 개요


| 항목    | 내용                                                                       |
| ----- | ------------------------------------------------------------------------ |
| 기간    | 4주 (주 1회 세미나 + 1주일 과제 기간)                                                |
| 대상 수준 | JS는 익숙하지만 React는 처음인 부원                                                  |
| 기술 스택 | React + TypeScript, Tailwind CSS, 전역 상태관리 라이브러리, Vercel 배포               |
| 진행 방식 | 매주 세미나(개념 + 라이브 코딩) → 1주일간 과제 구현 → PR 제출 → 다음 세미나 시작 전 리뷰                |
| 과제 구성 | 필수 과제(⭐️⭐️) / 심화 과제(⭐️⭐️⭐️~⭐️⭐️⭐️⭐️) / 키워드 과제(개념 정리) — 3차 세미나 예시와 동일한 포맷 |
| 최종 목표 | 4주차에 "내가 만들고 싶었던 것"을 스스로 기획부터 배포까지 완주                                    |


---

## 1. 전체 로드맵 한눈에 보기


| 주차  | 핵심 키워드                                     | 우리가 만드는 것                                 |
| --- | ------------------------------------------ | ----------------------------------------- |
| 1주차 | Figma 이해, React 초기 세팅, Tailwind            | Figma 시안을 그대로 옮긴 정적 UI + **4주차 아이디어 기획서** |
| 2주차 | 컴포넌트, Props/State, 이벤트, TypeScript, 라우팅 기초 | 1주차 정적 UI에 인터랙션을 붙인 동적 컴포넌트               |
| 3주차 | API 연동, 데이터 흐름, (심화) 전역 상태관리               | 여러 페이지 + 데이터 연동이 되는 미니 앱                  |
| 4주차 | 기획→구현→배포 전 과정                              | **개인 파이널 프로젝트 (Vercel 배포)**               |


1주차에서 "그림(디자인)을 읽는 법"과 "도구 세팅"을 익히고, 2주차에서 "그 그림을 살아 움직이게" 만들고, 3주차에서 "외부 세계(API)와 연결"하고, 4주차에서 이 모든 걸 합쳐 **자기 아이디어를 처음부터 끝까지 완주**하는 흐름입니다.

## 6. 1~4주차 비교표 (마무리 세미나에서 보여주면 좋은 표)


|        | 1주차    | 2주차        | 3주차                | 4주차             |
| ------ | ------ | ---------- | ------------------ | --------------- |
| 결과물    | 정적 UI  | 인터랙티브 컴포넌트 | 데이터 연동 미니 앱        | **개인 파이널 프로젝트** |
| 다루는 상태 | 없음     | 로컬 state   | 로컬 + (심화) 전역 state | 전체 종합           |
| 데이터    | 없음(더미) | 없음(더미)     | 외부 API             | 자유              |
| 페이지 수  | 1개     | 1개         | 2개 이상              | 자유(2~3개 권장)     |
| 접근 범위  | 나만     | 나만         | 나만                 | **누구나 (배포)**    |
