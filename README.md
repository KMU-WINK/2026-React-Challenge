# 아이디어 기획서

내가 챌린지를 통해 만들어보고 싶은 것

## 서비스 소개

**우리 학교 학생식당의 오늘 메뉴와 학생들의 한 줄 리뷰를 모아 보는 서비스**입니다.
식당에 가기 전에 오늘 메뉴가 무엇인지, 먹어 본 사람들은 어땠는지를 한 곳에서 확인하는 것이 목표입니다.

## 대상 사용자와 해결할 문제

- 대상: 학교 안 학생식당을 자주 이용하는 학생
- 문제: 오늘 메뉴는 ON국민에 있지만 학생메뉴창에 들어가기 번거롭고, 메뉴가 괜찮은지 후기를 확인할 곳이 없음

## 화면 구성 (3개)

1. **목록 화면**: 오늘의 식당별 메뉴 카드(식당 이름, 메뉴, 가격, 평균 별점), 끼니 탭(전체/조식/중식/석식), 별점순·최신순 정렬
2. **상세 화면**: 메뉴 상세 정보, 평균 별점, 리뷰 목록
3. **리뷰 작성 화면**: 별점, 한 줄 리뷰, 닉네임 입력

## 주차별 계획

| 주차 | 내용 |
| --- | --- |
| 1주차 | 정적 UI 퍼블리싱 (목록 카드·탭·헤더) |
| 2주차 | 컴포넌트 분리, 끼니 탭 필터와 정렬 State, 화면 이동(라우팅) |
| 3주차 | 데이터 연동 (직접 만든 목 데이터 또는 공개 API), 메뉴·리뷰 목록 불러오기 |
| 4주차 | 리뷰 작성 기능 완성, 다듬기, 배포 |

## 범위에서 뺀 것

- 로그인, 회원가입 (닉네임만 입력)
- 결제, 식권 구매
- 식당 위치 지도, 이미지 업로드
