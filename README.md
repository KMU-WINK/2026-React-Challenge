# 2주차 키워드 정리

## State 끌어올리기(Lifting State Up)란 무엇이고 왜 필요한가요?

State를 그 값을 같이 써야 하는 컴포넌트들의 부모로 옮기고, 자식한테는 Props로 내려주는 거다. 실습할 때 상세 페이지에서 댓글을 추가해도 "댓글 3" 숫자가 안 바뀌어서 이상했는데, 댓글 목록 State가 CommentSection 안에만 있어서 PostDetail은 몇 개인지 몰랐기 때문이었다. 이런 것처럼 여러 곳에서 같은 값을 봐야 하면 위로 올려야 한다.

## React가 Virtual DOM을 사용하는 이유는 무엇인가요?

화면이 바뀔 때마다 진짜 DOM을 통째로 다시 그리면 느리니까, 가상으로 한 번 그려보고 이전이랑 비교해서 달라진 부분만 실제로 바꾸려고 쓴다. 좋아요 누르면 카드 전체가 아니라 하트랑 숫자만 바뀌는 게 이거 덕분이라고 이해했다.

## SPA와 MPA의 차이는 무엇인가요?

MPA는 페이지 이동할 때마다 서버에서 새로 받아와서 새로고침되고, SPA는 처음에 한 번 받아놓고 필요한 부분만 바꿔서 보여준다. 카드 눌러서 상세로 넘어갈 때 새로고침 없이 바로 넘어가는 걸 보고 이게 SPA구나 라고 생각했다.
